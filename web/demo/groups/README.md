# Groups demo geometry (synthetic)

Synthetic test geometry for the part-groups walkthrough, generated by `node demo/make-demo-geometry.mjs`. It is not a real vehicle.

- `body.stl` and `wheel_*.stl`: the built-in sample car as separate files (metres, nose −X, up +Z, 10 mm clearance).
- `rear_wing_A_12deg.stl`: the sample car's rear wing, a 0.42 m flat plate at about 12°.
- `rear_wing_B_flat_high.stl`: a nearly flat plate mounted higher.
- `rear_wing_C_20deg_long.stl`: a 0.55 m plate at about 20°.

Import the body and wheels first, then add the three wings with **Add parts**. Each wing becomes its own group.
