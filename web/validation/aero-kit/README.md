# Synthetic aero kit (test geometry)

Synthetic parts for validating aero-part modelling on the MX-5 validation body: rear wings (inverted NACA 6412 at 10°, low and raised; inverted NACA 4412 at 4°, raised), endplates, supports, a front splitter and canards. They are generated by `make-aero-kit.mjs` in the MX-5 validation frame (metres, nose −X, up +Z). They are not a real product and contain no customer data.

```sh
node validation/aero-kit/make-aero-kit.mjs
```

Results and OpenFOAM references: [VALIDATION.md](../../VALIDATION.md#aero-parts-synthetic-kit-on-the-mx-5).
