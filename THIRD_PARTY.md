# Third-party components

Easy CFD does not change the licenses of its dependencies. Preserve their upstream notices when distributing them.

| Component | Use | Upstream |
|---|---|---|
| OpenCFD OpenFOAM 2412 | Meshing, steady flow solution, forces | https://www.openfoam.com/ |
| Colima | Optional open-source macOS/Linux container runtime | https://github.com/abiosoft/colima |
| Open CASCADE / cadquery-ocp | STEP import and tessellation | https://github.com/CadQuery/OCP |
| VTK / VTK.js | Field extraction and browser visualization | https://vtk.org/ and https://github.com/Kitware/vtk-js |
| Trimesh, NumPy, SciPy | Geometry preparation and numerical processing | https://trimesh.org/ |
| FastAPI, Uvicorn, Pydantic | Local API and configuration validation | https://fastapi.tiangolo.com/ |
| React, Vite, TypeScript, Lucide | Browser applications (legacy and web) | https://react.dev/ |
| three.js | 3D rendering in the browser version (`web/`) | https://threejs.org/ |

The solver image is pinned to the multi-architecture manifest digest in `backend/easycfd/foam.py`. It is downloaded separately from OpenCFD. Application source does not bundle OpenFOAM source or executables.

The sample car and wing are generated by `backend/easycfd/geometry.py` and `web/src/geometry/sample.ts`, and are covered by this project's MIT license. The synthetic rear-wing variants in `web/demo/groups` are too.

Optional AhmedML reference downloads, if present under the ignored local data directory, are CC BY-SA 4.0, not MIT. Attribution: Neil Ashton, Danielle Maddix, Samuel Gundry, and Parisa Shabestari, “AhmedML: High-Fidelity Computational Fluid Dynamics Dataset for Incompressible, Low-Speed Bluff Body Aerodynamics,” 2024, https://arxiv.org/abs/2407.20801. Source: https://huggingface.co/datasets/neashton/ahmedml. The benchmark download includes its original LICENSE.txt.

## User-supplied MX-5 NC example

The supplied GLB embeds attribution to Nieve5677 for “Mazda Miata MX-5 Roadster 2009”, under CC BY 4.0. Derived STL geometry retains that attribution and is not MIT-licensed. Source, license links, modifications, and simulation limitations are recorded in [docs/mx5-nc.md](docs/mx5-nc.md). The original and converted geometry are kept in the ignored local data folder.
